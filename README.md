# 🔍 JSON Explorer

JSON 데이터를 트리 구조로 시각화하고, 노드별 접기/펼치기, 실시간 검색, JSONPath 경로 복사를 지원하는 인터랙티브 브라우저 도구입니다.

## ✨ 주요 기능

- 🌳 JSON 트리 구조 시각화
- 🔄 노드별 접기/펼치기
- 🔎 실시간 검색 + 하이라이팅
- 📋 JSONPath 경로 원클릭 복사
- ❌ 구문 에러 표시
- 📂 텍스트 붙여넣기 / 파일 드래그앤드롭 / URL fetch 입력

## 🛠️ 기술 스택

- React + Vite
- Tailwind CSS
- GitHub Pages

## 🚀 시작하기

```bash
npm install
npm run dev
```
